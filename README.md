# diariocamino.eu

Sitio complementario del libro *Mi Diario del Camino de Santiago · Camino Francés*: las páginas que abren los códigos QR impresos (albergues, tiempo, mapa, GPX y avisos de cada etapa).

Publicado con GitHub Pages en **https://diariocamino.eu**. Los archivos se generan automáticamente a partir de los datos del libro: no se editan a mano.

Datos del recorrido © colaboradores de OpenStreetMap (ODbL). Altitudes: EU-DEM (Copernicus).
